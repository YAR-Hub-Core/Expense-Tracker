
# Expense Tracker

A Python-based expense tracking application that stores expense records in a JSON file.

## Features
- Add expenses with name, category, amount, and date
- View all expenses
- Calculate total expenses
- Delete expenses
- Generate category-wise reports
- Generate monthly expense reports
- Validate monthly report input

## Technologies Used
- Python
- JSON
- File Handling
- Functions
- Loops and Conditions
- Exception Handling

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python main.py

## Files
- `main.py` — Main application
- `expenses.json` — Expense data storage
- `README.md` — Project documentation
